# [RR-11] Backend Security Core - JWT Validation

- **Summary:** Xây dựng cơ chế xác thực JWT phân tán tại tầng `pkg/base`.
- **Priority:** `HIGH`
- **Type:** Infrastructure

---

## 📖 User Story
> As a developer, I want my microservice to automatically verify incoming tokens so that I don't have to write repetitive auth logic for every endpoint.

## 🔍 Acceptance Criteria
### Scenario 1: In-memory Verification
- **Given:** Service is starting up.
- **When:** It initializes the Auth Middleware.
- **Then:** It fetches the JWKS from Identity Server and caches the public keys.

### Scenario 2: Token Validation
- **Given:** A request arrives with a valid JWT signature.
- **When:** Middleware processes the request.
- **Then:** It parses the claims (user_id, role) and stores them in the Request Context.

### Scenario 3: Unauthorized Block
- **Given:** A request arrives with an expired or invalid token.
- **When:** Middleware processes the request.
- **Then:** It returns `401 Unauthorized` with a Problem Details JSON response.

## 🛠️ Technical Notes
- Package: `github.com/golang-jwt/jwt/v5`.
- Optimization: JWKS caching with background refresh.
- Scope: Implementation in `src/pkg/base/auth.go`.
