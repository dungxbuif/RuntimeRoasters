# [RR-22] Retail POS & Order Management

- **Summary:** Business process for over-the-counter ordering and order management.
- **Priority:** `HIGH`
- **Description:** Defines how the system receives orders from store staff, validates them, and initiates the supply chain processing flow.

---

## 🔍 Acceptance Criteria

### Scenario 1: Successful Order Placement
- **Given:** Staff selects bean type and quantity.
- **When:** Clicks "Place Order."
- **Then:** The system creates an order with the status `PENDING`.

### Scenario 2: Tracking Order Status
- **Given:** An order has been created.
- **When:** The Saga flow runs (Warehouse -> Logistics).
- **Then:** The order status updates automatically from `PENDING` -> `PREPARING` -> `SHIPPING` -> `COMPLETED`.
