# Security Policy

## Supported Versions
Only the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

We take the security of Runtime Roasters seriously. If you discover a security vulnerability within this project, please **do not** disclose it publicly or open a public issue.

Instead, please send an e-mail to the repository owner directly. Security vulnerabilities will be promptly addressed.

When reporting an issue, please provide:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any possible mitigation strategies you might suggest.

Thank you for helping keep this project secure!
