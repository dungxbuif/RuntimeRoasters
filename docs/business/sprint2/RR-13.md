# [RR-13] End-to-End Secure Integration

- **Summary:** Kiểm chứng luồng bảo mật toàn diện từ Client tới Backend.
- **Priority:** `HIGH`
- **Type:** Verification

---

## 📖 User Story
> As a project owner, I want to see a fully secured end-to-end flow so that I can verify the system is ready for business data.

## 🔍 Acceptance Criteria
### Scenario: Fully Protected Endpoint
1. **Unauthenticated:** Request fails with 401.
2. **Authenticated but Wrong Role:** Request fails with 403.
3. **Authorized:** Request succeeds with 200 and data is returned.

## 🛠️ Verification Steps
- Login via Client App.
- Trigger protected Ping endpoint.
- Verify audit logs in Jaeger showing the user identity in the trace tags.
