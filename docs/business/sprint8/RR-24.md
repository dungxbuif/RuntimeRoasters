# [RR-24] Redis Geo Tracking Integration

- **Summary:** Tích hợp Redis Geo để theo dõi vị trí xe tải.
- **Priority:** `MEDIUM`
- **Description:** Sử dụng các lệnh `GEOADD` và `GEOPOS` của Redis để lưu trữ và truy xuất tọa độ GPS của tài xế theo thời gian thực.

---

## 📋 Sub-tasks
- [ ] **Sub-task 24.1**: Cấu hình kết nối Redis Cluster cho Logistics Service.
- [ ] **Sub-task 24.2**: API/Consumer nhận tọa độ hiện tại (lat, long) và sử dụng `GEOADD` để lưu vào Redis với key là `driver_{id}`.
- [ ] **Sub-task 24.3**: API `GET /logistics/track/{shipment_id}` dùng `GEOPOS` lấy tọa độ realtime phục vụ bản đồ Frontend.
