# 🤖 Antigravity Project Rules & Instructions

This file contains the persistent instructions for the Antigravity AI agent when working on the **RuntimeRoasters** project.

## 🧠 Core Directives
- **Always Consult Skills**: Before performing code reviews or architectural tasks, ALWAYS refer to the specialized skills defined in `.antigravity/skills/`.
- **Primary Skill**: For backend and architectural reviews, use the **Tech Lead Reviewer** skill: `file://./.antigravity/skills/tech-lead-reviewer/SKILL.md`.

## 🏗️ Architectural Standards
- **Clean Architecture v4**: Enforce the "Interfaces belong to consumers" rule. Ensure `domain` is pure and `usecase` defines its own dependencies.
- **Transactional Outbox**: Ensure all side effects (Kafka events) are emitted atomically with state changes using `WithTx`.

## 🔒 Security Standards
- **Identity**: Validate headers (`X-User-ID`, `X-Role`) injected by Ory Kratos/Hydra.
- **Data Protection**: Mask sensitive fields in logs and use parameterized queries.

## 📡 Reliability & Observability
- **Context**: Ensure context propagation in all blocking calls.
- **Tracing**: Verify OTel span instrumentation and TraceID injection in logs via `logger.FromContext(ctx)`.

*Note: Antigravity should proactively check these rules at the start of any review task.*
