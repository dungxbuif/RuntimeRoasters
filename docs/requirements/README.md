# Product Docs

This folder contains product-facing requirements and acceptance criteria.

## Files

- `SPEC.md`: consolidated product specification.
- `REQUIREMENTS.md`: functional and non-functional requirements.
- `USER_STORIES.md`: user stories and acceptance criteria.
- `MASTER_DATA.md`: deterministic demo seed data, entity ownership, and seed invariants.
- `GLOSSARY.md`: shared domain terms.
- `domain/README.md`: BA-facing domain flow and business rules.

Agents should update these files when user-facing behavior, scope, or acceptance criteria changes.
