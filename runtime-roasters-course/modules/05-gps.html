Module 5

Real-Time Driver GPS

How Valkey tracks delivery driver locations in real-time using geospatial coordinates.

Geospatial Querying

When driver locations are constantly changing, writing them to a standard SQL database like PostgreSQL creates massive write overhead. Instead, we use Valkey.

Valkey has native support for geospatial indexes, which makes it extremely efficient to store GPS positions and quickly query which drivers are closest to a retail store.

The Push-Pin Metaphor

📍
Putting Pins on the Board

Every time a driver sends a GPS coordinate, it is like pinning their location on a grid board. Valkey keeps this board entirely in system memory for instant lookups.

⚡
Drawing a Circle search

To find nearby drivers, the server asks Valkey: "Find all driver pins within a 5-mile radius of Store A." Valkey computes this in milliseconds.

The Location Saver

Let's look at the Go implementation in the logistics-service. It saves the driver's coordinates and updates their "last seen" timestamp in Valkey:

GO CODE 
func (s *Service) storeDriverLocation(ctx context.Context, driverID string, lat float64, long float64) error {
  err := s.rdb.GeoAdd(ctx, driverLocationsKey, &redis.GeoLocation{
    Name:      driverID,
    Longitude: long,
    Latitude:  lat,
  }).Err()
  if err != nil {
    return err
  }
  return s.rdb.Set(ctx, "driver:last_seen:"+driverID, time.Now().Format(time.RFC3339), 90*time.Second).Err()
}
PLAIN ENGLISH

Define a helper function that takes the driver ID, latitude, and longitude, and saves them.

Call the Valkey GeoAdd command to store the driver's ID and coordinates under the geospatial index key.

Provide the specific longitude first, then the latitude matching Valkey's coordinate standard.

Check if the Valkey Geospatial operation returned an error. If so, fail immediately.

No error? Set a standard key-value entry with a 90-second expiration to track when we last heard from the driver.

Return nil (no error) to indicate the driver location was successfully recorded.

💡
Vibe Coder Insight: Expiring Keys

Valkey allows you to set a "Time to Live" (TTL) on any key (e.g. 90*time.Second). Once that time expires, Valkey deletes the key automatically. This is perfect for heartbeats — if a driver's phone loses signal or battery dies, the driver disappears from the active dashboard map automatically because their "last_seen" key expires.
