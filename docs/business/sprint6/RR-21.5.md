# [RR-21.5] Retail Store Seeding & Management

- **Summary:** Set up retail store information and seed data.
- **Priority:** `MEDIUM`
- **Description:** Defines the data structure for Stores and performs data seeding for 3 major cities (Hanoi, HCM, Da Nang).

### Scenario 1: Successful Data Seeding
- **Given:** The system is launched for the first time.
- **When:** Running the seed script/migration.
- **Then:** 5 stores across 3 major cities are created in the DB.

### Scenario 2: Querying Store List
- **Given:** The database already has data.
- **When:** Calling API `GET /stores`.
- **Then:** Returns the correct list of stores.
