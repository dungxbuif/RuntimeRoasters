# Release Notes: v1.0.0 (The "Cloud Native Farm-to-Cup" Release) ☕🚀

Welcome to **RuntimeRoasters v1.0.0**, the first official production-ready release! 
This milestone marks the completion of our transformation from a set of isolated local development services into a robust, Enterprise-grade, Kubernetes-ready distributed system.

## 🌟 Major Milestones Achieved

### 1. Choreographed Sagas & Event-Driven Backbone
We successfully built a resilient order processing system spanning across `Retail`, `Payment`, and `Warehouse` services using the **Choreographed Saga Pattern**.
- **Transactional Outbox/Inbox:** Guaranteed consistency across database transactions and Apache Kafka messages.
- **Graceful Shutdown & Idempotency:** Services now employ `sync.WaitGroup` to wait for active messages and use deterministic `MessageID` deduplication in Postgres to survive Kafka redeliveries safely.

### 2. Real-Time Geolocation Tracking (Valkey GEO)
- Migrated from legacy HTTP polling to high-performance **WebSocket (SSE) event-driven ingestion** via the `Socket Service`.
- Integrated **Valkey GEO indexing** for real-time driver tracking (`Logistics Service`), bringing live movement visualization to the Admin Control Plane.

### 3. Comprehensive Traceability (CQRS)
- Implemented a unified `Trace Service` that consumes events from all business domains (Farm, Logistics, Warehouse, Retail, Audit).
- Denormalized event data is stored in **Elasticsearch** for blazing-fast full-text searches, allowing customers to scan a QR code and trace their coffee cup all the way back to the specific farm harvest.

### 4. Zero-Trust Identity & Security
- Integrated **Ory Kratos** and **Ory Hydra** for bulletproof Identity, Session, and OAuth2 management.
- Implemented **Timestamp-based Token Revocation** for instantaneous session invalidation.
- Removed all hardcoded `.env` fallbacks. Sensitive variables are now designed to be injected via **HashiCorp Vault / External Secrets**.

### 5. Kubernetes & Production Readiness
- **GitOps Configs:** Extracted non-sensitive settings into a unified `config.yaml` and K8s `ConfigMap` (`deployments/k8s/configmap.yaml`).
- **Unified Domain Routing:** Defined K8s `Ingress` bridging KrakenD API Gateway, Frontend Client, and Identity Proxy.
- **Unprivileged Containers:** Finalized a universal `Dockerfile.service` utilizing Alpine multi-stage builds running as the `nonroot` user.
- **Continuous Integration:** Enforced quality via `.github/workflows/ci.yml` (Trivy Security Scanning, GolangCI-Lint, and Unit Tests).
- **Probes:** Embedded `/health/live` and `/health/ready` endpoints with deep DB-ping checks across 100% of the microservices.

## 🛠 Next Steps (v1.1.0 Roadmap)
While v1.0 establishes our robust foundation, the journey continues:
- **Deployment:** Spin up the actual EKS/GKE cluster using Terraform and apply the K8s manifests.
- **Load Testing:** Introduce k6 to push the Saga framework to its limits.
- **Native Mobile Client:** Expose the KrakenD GraphQL/REST interfaces to a mobile app for field workers at the coffee farms.
