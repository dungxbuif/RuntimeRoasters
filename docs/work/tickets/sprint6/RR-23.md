# [RR-23] Retail Service & Saga Orchestrator

- **Summary:** Implement Retail Service with Outbox Pattern and Saga orchestration.
- **Priority:** `CRITICAL`
- **Description:** Build the core service for Retail, managing `orders` and `outbox` tables. This is the starting point of the Saga flow.

---

## 🔍 Acceptance Criteria

### Scenario 1: Atomic Order Creation
- **Given:** Request `POST /orders`.
- **When:** The system processes it.
- **Then:** Save Order to DB and save Event to Outbox in the same transaction.

### Scenario 2: Saga Rollback
- **Given:** Receive `StockReservationFailed` event from Warehouse.
- **When:** Process the event.
- **Then:** Update Order status to `CANCELLED`.
