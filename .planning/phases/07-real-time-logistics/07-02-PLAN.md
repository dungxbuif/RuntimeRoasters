  <action>
    - Implement `FindNearestAvailableDriver` in the driver repository using Valkey `GEOSEARCH` (WR-02) with `BYRADIUS`.
    - Implement `AssignShipment` use case:
      1. Receive Order info from Kafka event.
      2. Find nearest driver (radius 5km).
      3. Start DB Transaction:
         - Select driver for update (`IsAvailable = true`).
         - If no driver found, create `Shipment` in `PENDING` and return (background worker will retry).
         - If driver found:
           - Update `Driver.IsAvailable = false` (CR-03).
           - Create `Shipment` record in `ASSIGNED` state with `DriverID`.
           - Save an `OUTBOX` event for `logistics.shipment.assigned`.
    - Ensure atomicity to prevent double-assignment of drivers.
  </action>
