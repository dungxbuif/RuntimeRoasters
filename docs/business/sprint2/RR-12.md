# [RR-12] QR Lifecycle UI — Traceability Frontend

- **Summary:** Xây dựng giao diện quét mã QR hiển thị hành trình vòng đời sản phẩm từ dữ liệu Traceability GraphQL Engine.
- **Priority:** `MEDIUM`
- **Depends on:** `RR-11` (Traceability GraphQL Engine)
- **Description:** UI component cho phép khách hàng nhập hoặc quét mã QR để xem toàn bộ hành trình của sản phẩm cà phê theo dạng timeline trực quan (từ Lô thu hoạch → Mẻ rang → Chuyến xe → Cửa hàng).

---

## 🔍 Acceptance Criteria (BDD Specification)

### Scenario 1: Nhập QR Code và xem hành trình
- **Given:** User truy cập trang `/trace`.
- **When:** User nhập `qrCode = "RR-2024-001-ABC"` và nhấn "Tra cứu".
- **Then:** Trang hiển thị Timeline Card với các stage: `HARVEST → ROAST → SHIP → RETAIL`, mỗi stage có timestamp và metadata liên quan. Không có loading state dài hơn 1 giây.

### Scenario 2: QR Code không tồn tại
- **Given:** User nhập một mã QR chưa có trong hệ thống.
- **When:** GraphQL query trả về `null`.
- **Then:** UI hiển thị thông báo "Không tìm thấy thông tin sản phẩm" thay vì crash hoặc màn hình trắng.

### Scenario 3: Chọn độ sâu hiển thị (UI-configurable depth)
- **Given:** Timeline đang hiển thị ở mức cơ bản (Farm + Retail).
- **When:** User toggle "Xem chi tiết vận chuyển".
- **Then:** UI gửi GraphQL query mới với thêm field `shipment { vehicle departedAt }`, timeline mở rộng thêm stage vận chuyển mà không reload toàn trang.

---

## 🛠️ Technical Notes

- **Stack:** Next.js + React Query + `graphql-request` (lightweight GraphQL client).
- **GraphQL Client config:**
  ```ts
  const traceClient = new GraphQLClient('/api/trace/graphql', {
    headers: { Authorization: `Bearer ${token}` },
  })
  ```
- **UI component:** `<TraceTimeline />` — nhận `TraceResult` type và render các `LifecycleEvent` theo thứ tự chronological.
- **API Route (Next.js proxy):** `/api/trace/graphql` proxy về Trace Service để tránh CORS và ẩn internal URL.
