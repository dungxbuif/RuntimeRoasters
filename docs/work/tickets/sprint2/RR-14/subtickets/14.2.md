# [RR-14.2] Middleware Integration

- **Summary:** Tích hợp kiểm tra Blacklist vào gRPC Interceptor và Gin Middleware.
- **Status:** `TODO`

## 🛠️ Technical Design
- Cập nhật `GRPCUnaryInterceptor` để gọi `BlacklistChecker.IsRevoked`.
- Cập nhật `GinMiddleware` để gọi `BlacklistChecker.IsRevoked`.
- Phải xử lý lỗi Valkey một cách "Fail-Open" hoặc "Fail-Closed" tùy theo yêu cầu bảo mật (mặc định Fail-Open để đảm bảo Availability, hoặc Fail-Closed cho High Security). Trong bài toán này chọn **Fail-Closed** (Chặn request nếu không kiểm tra được blacklist).
