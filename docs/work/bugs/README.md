# Bugs

Use this folder for reproducible defects that need root-cause analysis and regression evidence.

Bug workflow:

1. Record raw feedback in `docs/work/FEEDBACK_LOG.md` or backlog.
2. Create a bug artifact from `BUG_TEMPLATE.md`.
3. Reproduce before fixing.
4. Identify root cause before implementation.
5. Add regression evidence and update `docs/work/VALIDATION_MATRIX.md`.

Do not use bugs for feature requests or broad design changes; use tickets instead.
