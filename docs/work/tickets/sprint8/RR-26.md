# [RR-26] Payment & Refund Flow

- **Summary:** Nghiệp vụ thanh toán đơn hàng và xử lý hoàn tiền.
- **Priority:** `HIGH`
- **Description:** Định nghĩa các kịch bản thanh toán thành công, thất bại và quy trình hoàn trả tiền nếu Saga bị rollback ở các bước sau.

---

## 🔍 Acceptance Criteria

### Scenario 1: Thanh toán thành công
- **Given:** Người dùng chọn phương thức thanh toán.
- **When:** Hệ thống Stripe báo thành công.
- **Then:** Chuyển trạng thái đơn hàng sang `PAID`.

### Scenario 2: Hoàn tiền (Refund)
- **Given:** Đơn hàng đã thanh toán nhưng bị lỗi ở Logistics.
- **When:** Saga kích hoạt Compensating Action.
- **Then:** Hệ thống tự động gọi API Stripe Refund.
