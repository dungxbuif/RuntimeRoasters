# [RR-12] Fine-grained Authorization (Casbin)

- **Summary:** Tích hợp Casbin để quản lý phân quyền chi tiết dựa trên Role và Resource.
- **Priority:** `MEDIUM`
- **Type:** Infrastructure

---

## 📖 User Story
> As a security officer, I want to define fine-grained access policies so that users only interact with data they are authorized to see.

## 🔍 Acceptance Criteria
### Scenario 1: RBAC Model Setup
- **Given:** Service is initialized.
- **When:** It loads the Casbin model.conf.
- **Then:** It supports standard RBAC logic (subject, object, action).

### Scenario 2: Policy Enforcement
- **Given:** A user with role 'VIEWER' attempts to `DELETE /v1/demo`.
- **When:** The enforcer checks the request.
- **Then:** It returns `403 Forbidden`.

## 🛠️ Technical Notes
- Library: `github.com/casbin/casbin/v2`.
- Policy Storage: CSV for dev, Postgres for production.
- Model: RBAC with domains (multi-tenancy ready).
